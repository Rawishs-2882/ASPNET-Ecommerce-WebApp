# ASPNET-Ecommerce-WebApp

Full-stack e-commerce platform built with ASP.NET Core and SQL Server, featuring secure authentication, an interactive shopping cart, and integrated payment processing.

## Features
- Secure user authentication
- Interactive shopping cart
- Integrated payment processing

## Tech Stack
ASP.NET Core, SQL Server, C#

## Setup & Run
1. Update the connection string in `appsettings.json`.
2. Run `dotnet ef database update` to apply migrations.
3. `dotnet run` to start the app.
